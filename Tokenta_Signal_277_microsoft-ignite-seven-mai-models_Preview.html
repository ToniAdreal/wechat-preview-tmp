CASE STUDY / 案例分析

2026 年 11 月 17 日，微软在旧金山 Ignite 大会首日一次发布 7 个自研 MAI 模型。MAI Code 2 与 MAI Code 2 Flash 做编程，MAI Cyber 2 Flash 做安全，MAI Image 2.7 做图像，MAI Realtime 1 做实时语音对话，MAI Transcribe 2 做语音转录，Decision 1.1 是路由模型。

头牌是 MAI Code 2。微软称，在 4 项编程基准均值上，Code 2 达到 GPT-6.1 Sol 编程水平的 98%，价格约 40%，达到 Claude Opus 5.5 的 96%，价格约 5%。模型卡数据是，Code 2 约 2.8 万亿总参数、770 亿激活参数，1M token 上下文。Flash 版约 3,980 亿总参数、120 亿激活参数。

落地渠道已经铺好。Code 2 与 Code 2 Flash 已进 GitHub Copilot，Code 2 覆盖 Pro、Pro+、Max、Business 与 Enterprise，Flash 从免费版起可用。Code 2 Flash 另在 Microsoft Foundry 有限预览。上一代 MAI-Code-1.1-Flash 将于 12 月 18 日从 Copilot 退役。

权重授权，不是开源
