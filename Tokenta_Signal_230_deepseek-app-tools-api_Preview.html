DEEPSEEK × APP API

02 · WHY TOKENTA SIGNAL · 230

DeepSeek整座App，拆成API开放

DeepSeek 11月13日把消费级App背后的整套能力开放给开发者，搜索、读链接、文件解析与安全检查都能通过API调用，按次单独计费。

App里的能力，现在都成了接口。

// SIGNAL 230 · EXECUTIVE BRIEF

DeepSeek把自家App拆成零件卖，开发者不用再自己拼搜索、解析和语音。这一招的对手不是模型本身，是那些帮开发者把零散能力拼起来的中间层。

CASE STUDY / 案例分析

工具清单分两层。第一层是内置的，调用模型时直接带上，网页搜索、链接读取、文件输入与安全检查都在里面。搜索支持思考模式下的多步深度搜索，文件输入覆盖PDF、Word、PowerPoint、图片，纯文本提取或富版式解析都能做。第二层是独立的，搜索、抓取、OCR、语音识别与语音合成各自成API，按次或按量单独计费。

价格表是这件事最显眼的部分。搜索与抓取同价，每千次成功请求0.75美元。OCR每千页0.225美元。语音识别每小时0.058美元，语音合成每万字0.225美元，语音两项都是限时五折。模型本身另算，deepseek-flash输入每百万token 0.30美元，输出1.20美元，高峰价，低谷减半。

安全检查是另一条线。参数会审查模型的输入与输出，有风险就返回拒绝标志。DeepSeek要求面向公众提供服务的开发者必须启用它，内容审核、模型备案与AI标识这些义务由开发者自己承担。官方还开源了一个浏览器演示客户端，MIT协议，能导入App导出的聊天记录，密钥与聊天只存在本地，明确标注仅供演示。

01 / WHY IT MATTERS

便宜的不是模型，是拼装成本

开发者做AI应用，最花时间的往往不是调模型，而是把搜索、解析、语音这些零散能力拼在一起，再各自维护账单与配额。DeepSeek把已经跑通的一整套直接拿出来，省掉的是这部分拼装活。

定价策略也很直白，工具费与token费分开，低价先把量拉起来。语音识别与合成都在限时五折，折扣没有写明截止时间，这一点要留意，账单上的价格以后可能会变。

02 / WHAT TO WATCH

合规责任，跟着接口一起交出去了

接下来要看两件事。第一，开发者实际接入的速度，演示客户端降低了试用门槛，但生产环境的要求一点没降。第二，安全检查在真实流量下的表现，拒绝标志准不准，直接关系到面向公众的服务能不能稳定跑。

更值得留意的是责任划分。内容审核、模型备案与AI标识，DeepSeek点名由开发者自己承担。接口越好用，这份责任清单越要先读清楚，能力开放的同时，合规成本也一起转手了。

01 / THE LAUNCH

11月13日，DeepSeek把App背后的整套能力开放给开发者，覆盖Messages、Responses与Chat Completions三个API。

02 / THE TOOLS

网页搜索含思考模式下的多步深度搜索，链接读取，PDF、Word、PowerPoint、图片与纯文本的文件输入，另有模型安全检查。

03 / PARADIGM SHIFT

从自家产品，到别人的零件

FROM APP TO API

从一款App，到一套接口

原来只有打开App才能用的能力，现在开发者可以直接调用。DeepSeek把自己的产品拆开，变成了别人产品的零件。

FROM TOKENS TO PER-USE FEES

从按token算，到按次算

工具费与token费分开收，搜索、抓取、OCR和语音各自按次或按量计价。模型本身继续按token计费，高峰与低谷价格差一半。

BOUNDARY / 边界与工程约束

价格数字出自官方文档，由二手来源整理呈现，更新日志本身没有列出价格。语音两项的五折优惠没有写明截止时间。语音合成支持10种语言、语音识别支持21种语言，来自二手来源。本篇不构成任何投资建议。

TOKENTA SIGNAL JUDGMENT

模型还在降价，能力开始单卖

Tokenta Signal判断：DeepSeek这次卖的不是一个更强的模型，而是一整套已经跑通的产品能力。搜索、读链接、文件解析、语音，这些原来藏在App里的功能，现在按次计费单独出售。定价压得很低，搜索和抓取每次千次成功请求0.75美元。对开发者来说，吸引力不在便宜，而在不用再自己维护一堆零散服务。风险也在明处，安全检查的责任推给了开发者，面向公众的服务要自己过内容审核、模型备案和AI标识这几关。
