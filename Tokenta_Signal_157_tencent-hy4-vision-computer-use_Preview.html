01 / FROM TEXT TO HANDS

“从纯文本，到会动手”

“Hy4 Preview 还是一个纯文本模型，三个月后 Hy4 把手伸进了屏幕。能看图，能读表，能点鼠标，模型的工作界面从对话框扩展到了软件本身。”

“厂商自报 OSWorld 2.1 得分 78.9，同一张表里 Claude Opus 5.5 为 81.8，Kimi K3.1 Pro 79.6，GPT-6.1 Sol 75.2。Hy4 排在第二梯队，离榜首只差不到 3 分。”

02 / HALLUCINATION CUT

“幻觉率砍了三分之二”

“腾讯自评幻觉率从 Preview 的 15.76% 降至 5.45%。GameDev 提升 19.1%，GameLogic 提升 9.8%。数字好看，但全部来自厂商自报，没有第三方复现。”

“幻觉率是电脑操作类模型最敏感的指标。点错一个按钮的代价，比答错一道题大得多。5.45% 这个数字，需要真实使用来验证。”

03 / API FIRST, WEIGHTS LATER

“先卖 API，权重随后”

“权重与系统卡承诺随后发布，至今未出。先上 API 再开源权重的顺序，说明腾讯这一次先要收入和反馈，再谈生态。”

“免费窗口只有 11 天，TokenHub 五折到年底。窗口期结束之后，Hy4 要靠实际表现留住用户，而不是靠发布会上的分数。”
