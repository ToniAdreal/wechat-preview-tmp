CASE STUDY / 案例分析

“美团 LongCat 团队在 11 月 1 日的技术公告与 11 月 2 日的 API 上线之间，推出了 LongCat-2.5。这是一个原生多模态模型，面向长时程智能体任务，总参数 1.6 万亿，每 token 激活约 480 亿。”

“模型的最大卖点不在参数量，在训练底座。美团称，长上下文训练与 4 位推理针对国产 AI 加速器做了优化，单张国产加速器的显存不到 80GB，训练系统因此优先保证显存效率。”

“模型已通过美团聊天服务与 API 提供，上下文窗口 100 万 token，最大输出 12.8 万 token，限时价为每百万输入 token 0.30 美元。GitHub 与 Hugging Face 发布标注为即将推出，尚未上线。”

01 / BIG TOTAL, SMALL ACTIVE

“参数大，激活小，账要分开算”

“1.6 万亿是总参数，480 亿是每 token 实际激活的参数，只占总数的 3%。混合专家架构的意义就在这里，模型可以很大，单次调用的成本不用跟着变大。”

“美团的 4 位量化方案把专家权重与激活值都压到 4 位。公司称这套配置在测试中与全精度模型表现相当。省下来的显存与算力，是国产芯片跑大模型的关键。”

02 / SELF REPORTED SCORES

“自报成绩单，要按自报成绩单读”

“美团自己的对照表里，LongCat-2.5 在 27 项与 GPT-5.6-Sol 共有的测试中，20 项得分更高，在与 Claude Opus 5 共有的测试中，10 项更高。这些数字来自美团自己的测试，部分对手分数来自公开报告或排行榜。”

“独立验证还没有。权重尚未发布，第三方无法复现。把自报成绩直接读成行业排名，是这篇最容易踩的坑。成绩单的价值在于方向，不在于名次。”

03 / THE DOMESTIC CHIP LINE

“国产芯片这条线，越走越实”

“LongCat-2.0 在 6 月已经走过一遍国产芯片训练，官方称用了 5 万多张国产加速器，没有英伟达硬件，权重后来以 MIT 协议开源。LongCat-2.5 是同一条线的第二步。”

“这条线的意义不在单点突破，在可复制。同一套优化方法从一代用到二代，说明国产加速器跑大模型已经从实验变成了流程。流程一旦成立，规模只是时间问题。”
