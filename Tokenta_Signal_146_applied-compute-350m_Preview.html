CASE STUDY / 案例分析

“Applied Compute在公司博客宣布，成立不到18个月，公司已从零做到1亿美元年化收入 run rate，并完成3.5亿美元新一轮融资，估值32.5亿美元。本轮由Elad Gil领投，参投方包括Kleiner Perkins、Lux Capital、英伟达、Blackstone、Shopify Ventures与HubSpot Ventures等。”

“公司由三名前OpenAI研究员在2025年创立，做的是企业专属智能。简单说，帮企业用自己的数据与领域知识，训练、部署并运行定制化的AI智能体，而不是直接卖一个通用模型。”

“公司称自7月以来客户已在AC2平台上跑了超过1700次训练，团队规模自1月以来翻了三倍，其中85%是研究员与工程师。公司自述的客户包括微软、Shopify、Mercor、Harvey、DoorDash、Cognition、Clay与Decagon。”

VALUATION

01 / SPEED AS THE THESIS

“18个月，1亿美元，速度本身就是论点”

“一家2025年成立的公司，18个月做到1亿美元年化收入，这个速度在企业AI赛道里很罕见。上一轮的公开讨论还在30亿美元估值附近，新一轮直接定在32.5亿美元。”

“速度背后是定位。Applied Compute不跟基础模型厂商拼模型本身，它拼的是把开源模型与企业数据接起来的工程能力。企业要的不是更强的模型，是能跑在自己业务上的模型。”

02 / SPECIFIC, NOT GENERAL

“专属智能，卖的是定制不是模型”

“通用模型解决的是所有人的平均问题，企业要解决的是自己的具体问题。Applied Compute的打法是让企业用自有数据做出专属智能体，知识留在企业内部，能力跟着业务走。”

“这条路线的好处是客户粘性。模型一旦接进业务流程、跑出1700多次训练，换供应商的成本就很高。坏处也一样，定制化越深，扩张速度越依赖服务与交付能力。”

03 / WHAT THE MONEY BUYS

“融资用来扩算力与招人，扩张的考验在后面”

“公司表示新资金将用于扩大算力容量、扩招团队、加速企业部署。这三件事都是扩张期的标准动作，真正的问题是1亿美元 run rate里有多少是可持续的订阅收入，有多少是一次性部署收入。”

“公司没有披露这个拆分。估值32.5亿美元对应约32.5倍 run rate，这个倍数成立的前提是收入继续高速增长并且留存率过硬。下一轮的考验不是融资能力，是续约率。”
