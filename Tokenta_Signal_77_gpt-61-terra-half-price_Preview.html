// SIGNAL 77 · EXECUTIVE BRIEF

“OpenAI 在 10 月 26 日发布 GPT-6.1 Terra，中档模型，主打视觉推理与电脑操作，标准 API 价为每百万输入 token 1 美元、输出 5 美元，OpenAI 称比上一代 Terra 与 GPT-6.1 Sol 低一半。”

CASE STUDY / 案例分析

“GPT-6.1 Terra 的定位是 OpenAI GPT-6 家族的中档：不在旗舰位置，却对准了办公室里重复量最大的活——读发票、填表单、看技术图纸、起草提案。模型看屏幕、点鼠标、跨应用操作，把原来需要人坐在电脑前一格一格做的事，换成对话里的一句话。”

“价格是这次发布的真正主角：标准 API 价为每百万输入 token 1 美元、输出 5 美元，缓存输入 0.05 美元。OpenAI 称这比上一代 Terra 与同代 Sol 低一半。便宜的意义不在账单数字，而在部署门槛：原来因为单次成本太高而只能抽查的任务，现在可以全量跑。”

01 / THE TASK COST

“每 token 便宜一半，每任务便宜更多”

“按 token 计价会掩盖真实成本：一个任务花多少 token，取决于模型一次做对的概率。OpenAI 称 Terra 在 Agents' Last Exam 上比上一代高 15 个百分点、与旗舰 Astra 持平，同时完成任务的速度快三倍以上。”

“第三方分析的算法更直接：Artificial Analysis 称 Terra 的智能指数比上一代高 6 分，单任务成本从 1.40 美元降到 0.40 美元。价格表是标价，每任务成本才是收据。”

02 / THE ERROR RATE

“低努力下的错误率，是最值得盯的数字”

“OpenAI 自测的内部易错提示集上，低推理努力下的事实错误率从 53.6% 降到 16.7%，高努力下为 4.3%。这个数字比基准分更贴近日常使用：低努力正是批量任务的默认档位。”

“错误率没有降到零，意味着批量部署仍需一道人工复核。便宜让全量跑成为可能，复核决定了全量跑是否负责任。”

03 / THE DISTRIBUTION

“同一天上架三个平台，才是分发信号”

“发布当天，Terra 同步出现在 OpenAI API、ChatGPT Work 与 Codex、GitHub Copilot 以及 Amazon Bedrock。模型发布早已不只是发一篇博客，而是同一天铺进开发者已经在用的入口。”

“对买家而言，选模型之前先看自己已有的平台：账单、审计与权限体系都在平台里，模型只是换了一个名字。”
