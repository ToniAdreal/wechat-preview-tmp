Qwen4-Max 只给 API 不给权重，阿里换了打法

阿里巴巴 11 月 16 日发布 Qwen4-Max，总参数 2.4 万亿，每 token 只激活 710 亿，上下文 100 万 token。模型只走 API，不开放权重，输入每百万 token 1.5 美元。

2.4 万亿参数的旗舰不给权重，买家只能按调用量付费。

CASE STUDY / 案例分析

2026 年 11 月 16 日，阿里巴巴发布 Qwen4-Max，这是 Qwen 系列迄今最强的模型。它原生支持视觉，上下文窗口 100 万 token，定位是能干活的 AI 队友，不只是聊天工具。

价格贴在 QwenCloud 的价目表上，输入每百万 token 1.5 美元，输出 4.5 美元，隐式缓存命中只要 0.075 美元。11 月 11 日它先在 Token Plan 上预览，5 天后才正式发布。

独立测试给了另一面。Artificial Analysis 的智能指数只给它 43 分，排在前沿集团中段，比 Kimi K3.1 Pro 低 3 分。Code Arena 编程榜第 6 名是它在厂商榜单之外的最好名次。

01 / WHY IT MATTERS

激活参数少了四分之一

Qwen4-Max 每 token 只激活 710 亿参数，比上一代 Qwen3.8-Max 少约 25%。总参数规模没变，算力账却变轻了，这是它敢把任务单价压下来的底气。

阿里自己的 Work360 评测说，高强度推理模式下每任务 token 用量少 35%，平均成本降约 60%。这组数字出自厂商自己的评测，没有独立复核。

02 / WHAT TO WATCH

小模型只剩一句话

发布稿只写了一句，小尺寸开源 Qwen4 模型将陆续发布，没有名字，没有尺寸，没有日期。上一代的开源节奏不能直接套到这一代身上。

想在本地跑 Qwen 旗舰的人，眼下只能等。Qwen3.8-Max 的开源权重还在，Qwen4-Max 的本地版本连时间表都没有。
