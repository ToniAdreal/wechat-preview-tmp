// SIGNAL 309 · EXECUTIVE BRIEF

Tokenta Signal判断：微软把 OpenAI 最新的日常模型铺进全球 Copilot，同时让自研模型在后面接走更多流量。

CASE STUDY / 案例分析

2026 年 11 月 20 日，微软在 Copilot 官方博客宣布，OpenAI 的 GPT-6.2 Sol 与 GPT-6.2 Astra 加入 Microsoft Copilot。Sol 面向全球符合条件的用户，在 Copilot Chat、Cowork、Studio 以及 Word、Excel 与 PowerPoint 里陆续上线。

Astra 的铺开窄得多。全面推送只覆盖 Cowork 与 Studio，进 Chat 与 Office 应用要加入 Frontier 早期计划。管理员在 Microsoft 365 管理中心控制开关，具体进度因地区与组织而异。

双线并行的背景是 2026 年 4 月 27 日修订的合作协议。微软不再向 OpenAI 分成，独家授权也已结束。同一周的 Ignite 大会上，微软推出 MAI Code 2 等自研模型，开始把更多流量留在自家模型上。

01 / WHY IT MATTERS

Sol 给所有人，Astra 留给重度用户

Sol 进了标准授权的每一个 Copilot 入口，Astra 只留在 Cowork、Studio 与 Frontier 用户手里。分层按成本划线，Astra 的 API 价是 Sol 的 4 倍。

OpenAI 的公开价目写着，Sol 输入每百万 token 2 美元，输出 10 美元，Astra 是 8 美元与 40 美元。重模型只放在愿意按量付费的场景里。

02 / WHAT TO WATCH

MAI 接走的流量不再分成

微软的自研 MAI 系列在 Ignite 发布，MAI Code 2 已进 GitHub Copilot。微软称它能达到 GPT-6.1 Sol 约 98% 的性能，成本只要 40%。这组数字出自厂商自己的说法，没有独立复核。

每一次请求从 OpenAI 模型挪到 MAI 模型，微软就少付一笔分成。Copilot 表面还是 OpenAI 的最新模型，底下的流量分配正在一点点挪位。
