CASE STUDY / 案例分析

“云端模型的参数结构是 2930 亿总量、每 token 激活 300 亿的混合专家架构，上下文窗口 100 万 token。公司称其在 SWE Pro 与 SWE 多语言测试中居首，在 SWE Verified 中居次，训练耗时从 4.5 个月压缩到 1.2 个月，推理效率提升 4.5 倍。”

“端侧是另一条线：开源的 Spark X2.6-4B 端侧模型与端云协同架构首次公开，任务路由准确率从 81.2% 提升到 96.1%，设备独立完成任务的比例从 12.8% 升至四成以上。定价同样激进：限时优惠后输入 0.9 元、输出 3.6 元每百万 token。”

01 / THE COMPUTE

“国产算力，从口号变成训练账本”

“公司称 Spark X2.6 全部训练在国产算力上完成，飞星二号万卡集群用 1.2 个月跑完原本需要 4.5 个月的 2 万亿 token 训练量。数字来自厂商，验证需要第三方复现，但方向本身已经明确：国产算力的瓶颈正在从能不能训，转向训得多快。”

“配套的工程细节同样重要：长序列动态并行、分布式推理与四级键值缓存，都是为弥补国产加速器显存带宽短板而做的设计。模型发布会的另一半，其实是算力工程的发布会。”

02 / THE ROUTING

“端云协同，是比参数更实在的卖点”

“端云协同架构的含义很具体：简单任务留在设备上，复杂任务上云，路由模型决定分流。路由准确率 81.2% 到 96.1% 的提升，直接决定了用户体验与云端成本，参数规模反而退居次席。”

“开源 4B 端侧模型是这条路线的放大器：设备厂商可以免费拿到本地模型，再把重任务导向付费云端。上一代端侧模型累计下载 256 万次，说明这条分发路径已经跑通过一次。”

03 / THE TAAS

“从卖 token，到卖打包流程”

“与模型同步发布的还有 Agent OS、录制工作流技能工具与 Xingchen TaaS。TaaS 的含义是把模型、智能体与行业方案打包成可交付的工作流，而不是按 token 计费。”

“这一定位是对价格战的回应：当国产开源模型的 token 价格一路下探，厂商必须找到 token 之外的收费方式。TaaS 能否单独形成收入，要看未来财报是否单独披露。”
