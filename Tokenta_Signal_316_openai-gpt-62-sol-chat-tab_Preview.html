GPT-6.2 Sol 进驻 ChatGPT 聊天页，GPT-5.6 定在 12 月 23 日退役

OpenAI 11 月 23 日把聊天调优版 GPT-6.2 Sol 推向 ChatGPT 的 Chat 标签页，覆盖四档付费计划，GPT-5.6 Sol 与 Terra 将于 12 月 23 日退役。

OpenAI 在用退役时间表逼用户往前走，付费档先行，免费档继续等。

// SIGNAL 316 · EXECUTIVE BRIEF

Tokenta Signal判断：日常对话终于用上最新模型，代价是旧模型的退役日期已经写死。

CASE STUDY / 案例分析

这次进 Chat 标签页的是聊天调优版。OpenAI 在发布说明里写，它为日常对话做了优化，更擅长处理带细节要求的复杂请求，也更会联网找信息。图片理解是提升最大的一项，内部测试得分从 GPT-6 的 47.4% 升到 71.7%。

难指令的遵循率也涨了，从 62.5% 升到 78.1%。OpenAI 还举了两个日常例子，比酒店时按价格与位置权衡取舍，问到在售商品时主动提出降价提醒。青少年安全评估同样有提升，困难对话里符合安全政策的比例从 77% 到 80% 升至 91% 到 94%。

退役时间表同时公布。GPT-5.6 Sol 将退出 Chat、Work 与 Codex，GPT-5.6 Terra 同日退出 Work 与 Codex。免费版与 Go 用户这次不在范围内，继续用 GPT-6 Luna，OpenAI 没有给出它们升级的日期。

01 / WHY IT MATTERS

免费档被留在上一代

这次推送只覆盖四档付费计划，免费版与 Go 用户继续用 GPT-6 Luna。模型代际差第一次在 Chat 标签页里直接变成付费与免费的分界线。

OpenAI 没有给出免费档升级的日期。等待的时间越长，免费体验与付费体验之间的落差就越明显。

02 / WHAT TO WATCH

退役日期是真正的信号

这个退役日期比新模型本身更值得注意。它意味着 GPT-5.6 Sol 的用户只剩一个月过渡，旧模型不会悄悄留下来。

Work 与 Codex 的模型这次没有变化。Chat 标签页先换，专业场景后换，OpenAI 在按使用场景分批推进换代。

BOUNDARY / 边界与工程约束

图片理解与指令遵循得分出自 OpenAI 自己的内部测试，未经独立验证。推送正在分批进行，各账号看到新模型的时间可能有先后，企业版要管理员开启。GPT-5.6 Terra 是否留在 Chat 标签页，官方没有说明。
