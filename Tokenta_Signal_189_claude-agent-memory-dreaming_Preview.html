01 / FOUR LAYERS

“记忆分四层”

“Anthropic把智能体记忆定义为跨会话保留的经验知识，以可读文本的形式存在。模型权重、上下文学习和压缩都不算记忆。”

“四层从下往上是可搜的会话记录、模型写的记忆笔记、链接维基之类的表征层，以及每会话注入的一小段上下文。”

02 / DREAMING, OFFLINE

“做梦是离线纠错”

“做梦指离线遍历日志和记忆，把笔记逐条对照原文检验，改错、合并重复、搭建维基，再把笔记向上层提升。想法源自Letta与加州大学伯克利分校的睡眠时计算。”

“效果有实测。25题内部测试里，做梦整理后的维基把得分从13%抬到48%。搜索加维基比只搜记录高8个百分点，每题还省约2万个token。”

03 / POKÉMON RED TEST

“游戏是最好的试金石”

“宝可梦红版测试里，Sonnet 3.7写了413份记忆文件，只拿1枚徽章。Fable 5只写9份文件加1个仪表盘，拿了4枚。Opus 5.5直接通关。”

“做梦纠正了一条写错的宝可梦中心笔记，Claude才走到华蓝市，没纠错的那次跑法永远到不了。记忆写错了，比没有记忆更糟。”
