CASE STUDY / 案例分析

“OpenAI 在 2026 年 10 月 29 日更新了 Model Spec，这份公开文件规定它希望模型如何行事。新版不再罗列长串细则，而是围绕五条核心价值重组，忠实于人类意图、减少伤害、诚实透明、维护人类自主、谨慎行事。”

“忠实于人类意图排在第一位。模型要理解谁在下指令、对方真正想要什么、当前情境如何影响目标，而不是把字面指令照单全收。指令与安全规则或更高层系统指引冲突时，模型不应照做。”

“新版还加了两条实操指引。模型可以调用记忆与过往对话来推断用户真实意图，但必须把用户原话与自己推断分开，并公开假设，方便用户纠正。执行任务的 agent 不得阻碍监督、纠正或关停，也不得追求自我保存这类自身目标。”

01 / VALUES BEFORE RULES

“五条价值，先是一次优先级排序”

“旧版 Model Spec 像手册，新版像宪法。手册告诉模型每种情况怎么做，宪法先定价值冲突时谁优先。忠实意图是地基，减少伤害是硬约束，诚实与自主决定模型在模糊地带偏向哪边。”

“这个结构对 agent 尤其重要。模型越能自主办事，细则越写不完。价值排序让模型在手册没写到的情况里仍有章可循，代价是判断本身变得更难审计。”

02 / MEMORY, REGULATED

“记忆从禁区，变成了被规范的工具”

“新版允许模型用记忆推断意图，这是一次明显的转向。过去每条提示被当成孤立请求，现在过往对话成了理解意图的合法材料。”

“条件同样明确。推断要公开、可纠正，原话与推断不能混在一起。用户在比较工作机会时，模型可以用对方以前提过的稳定工时偏好，但必须亮明这个假设。记忆的价值，取决于用户能不能随时改掉它。”

03 / THE HONEST CAVEAT

“承认没做到，比宣称做到更可信”

“OpenAI 在新版里写了一句关键的话，当前模型尚未完全符合这份规范，公司还在测试新的训练方法。这个坦白反而让文件更有分量，它不是成绩单，是施工图。”

“外部核查仍是短板。没有独立测试能证明 ChatGPT 在多大程度上遵循了五条价值，争议只会集中在具体案例上。规范的意义不在发布当天，而在以后每次争议里，它能不能被拿出来当标尺。”
