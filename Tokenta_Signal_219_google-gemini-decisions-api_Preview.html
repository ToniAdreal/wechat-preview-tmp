// SIGNAL 219 · EXECUTIVE BRIEF

“谷歌11月11日发布Gemini Decisions API，搭载新模型Gemini Decision 1。一次请求可对同一份多模态输入并行回答最多1000道题，返回概率与置信度分数，零输出token。”

CASE STUDY / 案例分析

“Gemini Decisions API不是聊天模型。它一次请求能对同一份多模态输入并行回答最多1000道题，是非题、选择题、评分题都行。”

“输入可以是文本、图像、音频、视频、PDF，最高256K token。单次前向传播返回概率与置信度分数，零输出token。”

“端到端延迟150到250毫秒，模型计算部分50到100毫秒。定价每百万输入token 0.10美元，输出不收费，另有免费档。”

01 / NO WORDS

“模型不写字，只做选择题”

“大模型过去的输出是文字，文字要解析，要校验，要防幻觉。Decisions API把输出收敛成概率与分数，机器直接能用。”

“这个设计瞄准的是工具选择、策略检查、模型路由、上下文评分这些有界决策场景。答案越结构化，越适合交给程序。”

02 / 1000 IN ONE PASS

“一千道题，一次前向传播”

“并行回答1000道题，是这款API最反直觉的地方。传统做法是一道题一次调用，成本与延迟都线性增长。”

“一次前向传播出1000个分数，成本结构变了。决策密集的场景，比如给一千条内容打分，第一次有了便宜做法。”

03 / V1BETA ONLY

“先上API，Vertex随后”

“发布走Gemini API的v1beta端点与Google AI Studio，Vertex AI支持标注即将推出，没有日期。”

“发布次日，OpenRouter、LangChain、Vercel与LiteLLM的集成已经在推进。生态接得快，说明需求真实存在。”

“从生成文字，到输出判断”

FROM TEXT TO SCORES

从聊天回答，到结构化决策

模型输出从自由文字收敛成概率与分数，程序可以直接消费。决策场景第一次有了原生模型接口。

FROM OUTPUT TO INPUT PRICING

从按输出收费，到按输入收费

零输出token意味着输出不收费，账单只算输入。决策密集的任务，成本模型彻底变了。

TOKENTA SIGNAL JUDGMENT

“谷歌新模型不写字，只做选择题”
