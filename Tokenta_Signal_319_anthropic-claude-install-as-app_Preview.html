Claude做的工具能装成桌面应用了，权限分三档

Anthropic 11月24日推出 Install as app 测试版，Claude 里做出的 artifact 能装成 Mac 与 Windows 桌面应用，自带图标与窗口，权限分三档，全套餐可用。

聊天里随手做的小工具，终于能像正经应用一样住进电脑。

// SIGNAL 319 · EXECUTIVE BRIEF

Tokenta Signal判断：Install as app 把做应用的门槛压到一句话，真正的产品是那套三档权限。

CASE STUDY / 案例分析

11月24日，Anthropic 推出 Install as app 测试版，Claude 里做出的 artifact 能装成 Mac 与 Windows 桌面应用。装好之后它有自己的图标与窗口，不用再回到对话里找。打包、签名与 API 密钥都不需要，应用跑在用户自己的 Claude 账号上，改 artifact 就自动更新。

权限分三档。默认档只能做浏览器里能做的事。应用权限档可以发通知、监听全局快捷键、置顶窗口、往菜单栏或系统托盘加一项。完整电脑访问档可以运行程序、读写与删除文件，每次更新都要重新授权，Anthropic 不会在安装前审查应用。

覆盖面已经铺开。测试版面向全部套餐，Team 默认开启但完整访问关闭，Enterprise 要管理员手动开启。HIPAA 配置组织与混合部署用不了，文档、幻灯片与表格三类模板 artifact 也装不了，打开应用必须联网并登录 Claude。

01 / WHY IT MATTERS

小工具第一次有了自己的住处

artifact 过去是聊天里的一次性产出，用完就沉底。现在它能住进 Dock 与开始菜单，每天打开就能用，个人软件的形态变了。

这一步瞄准的是那些不值得立项的小需求。会议准备页、订单追踪器、番茄钟，这些工具以前要么没有，要么靠脚本凑合。一句话做出来再装上，成本低到可以随手做。

02 / WHAT TO WATCH

不审查应用，信任就得用户自己扛

Anthropic 明确说了，安装前不审查应用。完整访问只能给自己做的应用，Team 与 Enterprise 里也只能给同事做的，但判断最终还是落在用户手里。

自动更新是另一处要留意的。artifact 一改，装好的应用跟着变，每次更新都会重新要权限，这道关卡不能省。调用 Claude 的次数计入套餐用量，用得多就占得多。

FROM CHAT PANEL TO DESKTOP APP

从对话里的面板，到电脑里的应用

artifact 过去只能在聊天窗口里打开，现在有了自己的图标与窗口，打开方式和别的软件一样。

FROM PACKAGING TO PERMISSIONS FIRST

从打包签名，到先定权限再运行

不用打包、不用签名、不用 API 密钥，装应用之前先定好它能碰什么。

BOUNDARY / 边界与工程约束

测试版阶段，功能与覆盖范围可能调整。Anthropic 安装前不审查应用，完整电脑访问只给自己或同事做的应用，仍有风险。Linux、网页与移动端不支持，必须联网并登录 Claude 才能打开应用。
